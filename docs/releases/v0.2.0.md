# AppUninstaller 0.2.0

This version adds six interface languages and an immediate, saved light/dark theme switch. Windows x64 portable download: `AppUninstaller-v0.2.0.exe`.

## Added

- Choose English, Russian, French, German, Spanish or Italian in **Settings → Appearance & language**, using each language’s native name.
- Change between **Light** and **Dark** directly in Settings. The palette covers application surfaces, text, inputs, selections, warnings and confirmation dialogs.
- Keep both display choices between launches. Existing settings migrate with English and Light defaults while retaining the startup-update preference.
- Translate navigation, inventory controls, removal states, leftover/quarantine recovery, confirmation dialogs, update actions and ownership explanations through an embedded catalog.

## Improved

- An already displayed status changes language immediately while retaining application names, file paths and other message values exactly.
- Failed preference saves restore the previous display choices. Unknown future language/theme values fall back without re-enabling a disabled startup-update check.
- Theme changes apply only when needed, preserving the existing reactive CPU/GDI renderer and sleeping background worker.

## Verification and limits

Automated checks cover translation completeness, placeholder preservation, literal UI catalog coverage, safe parameter substitution, settings migration/roundtrip, live status formatting and failed-save theme recovery, alongside the existing removal/recovery fixture tests. Exact completed commands are recorded in `docs/LOCALIZATION.md`.

This task did not launch the application, uninstall any software or install an update. Fresh 0.2.0 application/settings screenshots, translated text fit, actual theme switching and updated visible/hidden/restore performance measurements remain unverified. Existing screenshots and runtime evidence describe 0.1.2. Published release notes, licenses and technical diagnostic details retain their source language.
